Task "onlyImmCapture flag on lambda objects":
Repos: Frontend, Coordinator, StandardLibrary (its rt folder). Read the document, the paragraph "onlyImmCapture flag" under "Modes" and the section "forEach" (where the flag decides whether forEach needs a materialisation).
Goal: every Java object representing a Fearless object literal (a lambda) says whether the literal captures only imm bindings. The flag is visible in Java only, never in Fearless.
Definition: a literal has the flag when every binding its body uses from the enclosing scopes has an imm type. A captured local, parameter, or enclosing this (the receiver of the enclosing method, with that method's reference capability) counts as imm when its type is imm C[..], or a type variable that can only be imm; read, mut, iso, mutH, readH, read/imm X, and a type variable that may be mut do not count. A literal capturing nothing has the flag; the backend already makes such literals singletons (LiteralDeclarations.captureFree, used by ProduceSingleType.emitLit in Coordinator/src/naiveBackend).
Where the information is: the core AST (Frontend/FearlessFrontend/src/core/E.java) has no types on E.X, so the backend can not compute the flag from the AST alone. The type system knows the type of every binding when it types a literal (Frontend/FearlessFrontend/src/typeSystem/TypeSystem.java and Gamma.java, where Gamma.filterFTV computes the environment visible inside a literal). Record the flag where the backend can read it when it emits the literal: a field on core.E.Literal, or a set of literals computed by the type system and handed to the backend. Pick the smallest change and explain the choice in the PR description.
Emission: in Coordinator/src/naiveBackend, the anonymous class of a literal with the flag, or its singleton interface, implements the marker interface _base.OnlyImmCapture, declared in StandardLibrary/rt as an empty Java interface. Nothing else changes in the generated code.
Tests: in Coordinator, compile a small program holding literals that capture nothing, an imm local, a read parameter, a mut local, the enclosing this from an imm method and from a mut method, and a type variable with and without an imm bound; assert from the generated Java which classes implement _base.OnlyImmCapture, in the style of the existing backend tests.
Run TestAllFrontendCoordinatorIntegration.java. Open one PR per repository changed (Frontend, Coordinator, StandardLibrary), each description linking the others. If recording the flag in Frontend needs more than one boolean per literal, stop and report what it needs instead of doing it.
