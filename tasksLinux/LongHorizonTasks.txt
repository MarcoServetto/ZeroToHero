What it does

On Linux the manager's icon is no longer an AWT TrayIcon (legacy XEmbed, which on your KDE/X11 goes through xembedsniproxy, whose translated click never reaches the Java window, as your probe showed). It is now a StatusNotifierItem served on the session bus, KDE's native tray protocol: Plasma reads our properties and calls Activate on a left click and ContextMenu on a right click over D-Bus; both show the window. No fake input, no embedding, no native library and no FFI needed after all: gui.Sni (~200 lines) opens the bus's Unix socket, does the EXTERNAL handshake, frames/parses the few D-Bus types the item needs, registers with org.kde.StatusNotifierWatcher, and one virtual thread serves GetAll/Get/the item methods for the process life. Windows and macOS keep the AWT icon.

The loud failures carry over exactly: no watcher on the bus → "This desktop offers no system tray"; the watcher leaving (Plasma restart/crash) or the bus closing → "The desktop removed the Fearless icon from the system tray", fatal via #25's handler. There is no popup menu on Linux for now (Menu=/NO_DBUSMENU): showing is the click, quitting is in the window; a dbusmenu can be a follow-up if you want "Show/Quit" back.

Verified here (GNOME 50 with the appindicator extension)
busctl, an independent D-Bus implementation, calls our GetAll/Get/unknown property/unknown method and parses every reply (8 properties, 64x64 ARGB pixmap, the two proper error replies).
launch → close via WM → click the icon → window back and focused. One GNOME-specific finding, recorded in gui_gym.txt: the extension only sends Activate to a menu-less item on a double click; KDE sends it on a single left click.
extension disabled while running → removal dialog, OK, exit 1; disabled before launch → no-tray dialog.
SniTest (4 tests) covers framing/parsing and the GetAll body; 153 tests pass.
Your turn on KDE

Build from sni-tray (or wait for the merges), start the manager: the icon should now appear as a native Plasma tray entry (Plasma may put it under the "hidden icons" arrow the first time; you can pin it in the tray settings). Close the window, single left click the icon: the window should come back. If not, busctl --user get-property org.kde.StatusNotifierWatcher /StatusNotifierWatcher org.kde.StatusNotifierWatcher RegisteredStatusNotifierItems tells whether we registered, and the same busctl ... GetAll call as above tells what Plasma sees.
