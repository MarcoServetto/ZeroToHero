Delegated task: "Manager commands" (Opus 5.5, high)`:
We want to add a new capability to system: to send a message to the manager.
We should make this as 'typed' as possible. When it come to the path to register a new folder, it should take the list of bytes for the absolute path. Right now fearless has no way to read the hard drive and discover those, so they should be 'hardcoded'. We are going to introduce ways to fetch those later.
We also need functionalities (in UStr?) to turn an ustr in the list of bytes.
Open a PR with your proposed design.
