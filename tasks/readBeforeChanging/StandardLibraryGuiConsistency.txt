Good:
  mut .width(n: Nat): mut S
  mut .oval(WidthNat, HeightNat): mut Graphics
Bad:
  mut .width(w: WidthNat): mut S
  mut .oval(w: Nat, h: Nat): mut Graphics
Why: a plain number is taken only when the method name says what the number is; with two or more numbers the types say which is which, so a swap is a type error.
