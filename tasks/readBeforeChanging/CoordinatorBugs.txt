Good:
  A type replaced by a hand-written rt file keeps the source file and the lines of its Fearless declaration:
  _base/Lists$1c$0.class   is compiled from datatypes/collections/lists/list.fear
  imm _RunRecursion#(_,_) error line: 24 in file run_recursion.fear   is a frame of a stack trace
Bad:
  _base/Lists$1c$0.class   is compiled from Lists$1c$0.java
  a stack trace drops the frames of _RunRecursion#(_,_), since they come from a .java file
Why: a type replaced by an rt file is a Fearless type with a special implementation, and its frames are frames of the Fearless program.
