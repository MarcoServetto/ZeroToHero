Good:
  A type replaced by a hand-written rt file keeps the source file and the lines of its Fearless declaration:
  _base/Lists$1c$0.class   is compiled from datatypes/collections/lists/list.fear
  imm _RunRecursion#(_,_) error line: 24 in file run_recursion.fear   is a frame of a stack trace
Bad:
  _base/Lists$1c$0.class   is compiled from Lists$1c$0.java
  a stack trace drops the frames of _RunRecursion#(_,_), since they come from a .java file
Why: a type replaced by an rt file is a Fearless type with a special implementation, and its frames are frames of the Fearless program.

Good:
  The compilation cache decides from modification times and the listed files: a package is still built when its .built file lists the same files and lower packages, and is not older than its inputs.
  A source file replaced by another version with an older modification time (cp -p, an unzipped backup) keeps the cached jar.
  A project opened by another Fearless installation whose base.json is older keeps the cached jars.
  The user who swaps files behind the cache runs Delete cache.
Bad:
  .built records a hash of every source file, of every lower api json and of the installation, and the cache compares them.
Why: the cache is not signed. Guarding it against each way to change files behind its back (older modification times, another installation, an edited cache file) is a list with no end.
